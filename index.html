Giới thiệu

Tôi là Hồng, sinh viên Toán Tin quan tâm đến phân tích dữ liệu và ứng dụng AI. Tôi học thiết kế Web để trình bày thông tin rõ ràng và giới thiệu sản phẩm học tập.

Trong Lab01, tôi tập trung vào cấu trúc HTML có ý nghĩa, đường dẫn ảnh, bảng dữ liệu và biểu mẫu tĩnh.

Kỹ năng đang rèn luyện

Kiến thức

  • HTML: tổ chức nội dung bằng tiêu đề và các thẻ ngữ nghĩa.
  • SQL: đọc dữ liệu, lọc điều kiện và tổng hợp kết quả.
  • Power BI: trình bày dữ liệu bằng báo cáo trực quan.

Công cụ thực hành

  • Visual Studio Code để viết và đọc mã nguồn.
  • XAMPP và Apache để chạy bài qua localhost.
  • Git và GitHub để quản lý phiên bản bài tập.

Dự án học tập

Bộ sáu bài thực hành HTML

Bộ bài gồm sáu trang có cấu trúc HTML5 hoàn chỉnh, dùng ảnh từ Resources và liên kết quay về trang chính.

Mở danh sách sáu bài

Lộ trình học phân tích dữ liệu

Tôi dự định bắt đầu với truy vấn SQL, kiểm tra chất lượng dữ liệu, tạo biểu đồ và viết nhận xét. Mục tiêu là giải thích được ý nghĩa của số liệu.

Mục tiêu học tập

  1. Giải thích được cấu trúc head và body.
  2. Kiểm tra mọi href, src và label trước khi nộp.
  3. Chạy bài bằng Apache và ghi lại minh chứng.
  4. Lưu mã nguồn lên GitHub kèm lịch sử commit.

Nhật ký thực hành

Bài học về đường dẫn

index.html và các bài con nằm cùng thư mục nên link quay lại chỉ cần href="index.html". Ảnh nằm trong images nên src bắt đầu bằng images/.

Bài học về biểu mẫu

for của label phải trùng id của input. name là tên trường dữ liệu khi gửi form; nó không thay thế vai trò định danh của id.
